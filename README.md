# Woo Manager Plugin

افزونه مرکزی و API امن برای اپ مدیریت ووکامرس.

## نسخه 0.1.0

- صفحه تنظیمات فارسی
- نگهداری رمزنگاری‌شده کلیدهای سرویس
- Health API و فهرست سفارش‌های ووکامرس
- هسته اتصال تاپین
- درایور ملی‌پیامک و فراز SMS

## امنیت

توکن تاپین و اطلاعات پیامک فقط در وردپرس ذخیره می‌شوند و نباید داخل اپ موبایل یا Git قرار گیرند.
