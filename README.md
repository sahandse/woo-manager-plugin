# Woo Manager Plugin

افزونه مرکزی و API امن برای اپ مدیریت ووکامرس.

## نسخه پایدار 1.0.0

- اتصال یک‌بارمصرف، توکن دستگاه و لغو دسترسی
- API کامل سفارش، بازپرداخت، مشتری، محصول و مدل‌های متغیر
- دسته‌بندی، ویژگی، مقدار ویژگی و برند رسمی ووکامرس
- ثبت مرسوله تاپین، لیبل/فاکتور PDF و پیامک رهگیری
- رسانه، محتوا، گزارش، خروجی، پشتیبان و مرکز سلامت
- سازگاری با HPOS ووکامرس

## امنیت

توکن تاپین و اطلاعات پیامک فقط در وردپرس ذخیره می‌شوند و نباید داخل اپ موبایل یا Git قرار گیرند.

فایل نصب نهایی توسط Workflow با نام `Plugin Release` همراه وابستگی PDF ساخته می‌شود.
