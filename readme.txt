هسته مدیریت موبایلی ووکامرس با اتصال امن به تاپین، ملی‌پیامک و فراز SMS.

== Installation ==
1. پوشه افزونه را در wp-content/plugins بارگذاری کنید.
2. Woo Manager را فعال کنید.
3. از منوی «مدیر فروشگاه» تنظیمات سرویس‌ها را وارد کنید.
